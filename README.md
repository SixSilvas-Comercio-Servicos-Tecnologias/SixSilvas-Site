# SixSilvas - Site Institucional

Site institucional moderno, premium e responsivo para a **SixSilvas - Comércio, Serviços e Tecnologias**.

## Branches
- Branch base: `work`.
- Branch de implementação: `feature/work-sixsilvas-institucional`.

## Comandos
```bash
npm install
npm run dev
npm run build
```

## Entregáveis incluídos
- Arquitetura completa do site.
- Sitemap técnico e mapa de rotas.
- Wireframes textuais.
- Design system.
- Guia de identidade visual.
- Componentes reutilizáveis.
- Páginas institucionais principais.
- Conteúdo em português, sem Lorem Ipsum.
- Estratégias de SEO, performance, acessibilidade e landing pages.

Consulte `docs/arquitetura-site.md` para a documentação completa.
